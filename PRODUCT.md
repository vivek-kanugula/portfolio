## Product Principles

1. **Evidence Precedes Assertion** — Back every claim with concrete metrics (latency, concurrency, CPU utilization, star counts, PR links).
2. **Substance Over Ornament** — Let the system architecture, code rigor, and problem constraints command visual attention.
3. **Zero Friction Access** — Recruiters can view and copy contact information, download the ATS resume, or inspect GitHub repos in one click.
4. **Flawless Performance & Responsiveness** — Sub-second interaction times, no layout shifts, responsive across phone, tablet, and widescreen.

## Accessibility & Inclusion

WCAG 2.1 AA compliance across contrast ratios (≥4.5:1 for body copy, ≥3:1 for large text), visible keyboard focus indicators, fully keyboard-traversable modal dialogs, and screen-reader accessible ARIA labels.
